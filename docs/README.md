# Documentation

Design and architecture documentation for ProFinder. Start at **[Home](Home.md)**
for the table of contents.

These pages are kept in sync **both ways** with the
[GitHub Wiki](https://github.com/Strogolsky/proFinder_backend/wiki): edit the files
here via a pull request, or edit the Wiki pages in the browser — the other side
updates automatically. Mechanics, page-naming rules and one-time setup are in
[`.github/wiki-sync.md`](https://github.com/Strogolsky/proFinder_backend/blob/develop/.github/wiki-sync.md).

> Files 1–15 describe the **target architecture** (5 microservices on a RabbitMQ
> event bus). Where the current code and these documents disagree, the documents
> are the intended design and the code is the work in progress.
